# Для запуска

Не забудьте установить зависимости!

cd frontend - npm run dev
cd backend - npm run dev

**ВАЖНО!**
Перед запуском backend нужно запустить PostgreSQL у себя на компьютере и в файле .env DB_USER= указать имя юзера

При каждом запуске бэкэнда тестовые данные в хранилище будут обновляться на те, которые указаны в server.ts
Сделано это, чтобы тестировать удаление файлов и упростить их восстановление
Заблоговременно решена ошибка при переходе на не тот url, выдается ошибка и предлагает вернуть на главную
Также при переходе на несуществующую карточку продукта или не найденную, предлагает вернуться к списку назад
В поиске IP нельзя указать ничего кроме цифр и точки
